# Ferry Terminal Overruns

**This page is a deliberate fixture.** Its filename is not a valid slug — it
contains spaces and capital letters — so the collector reports it as
`non-slug-safe-filename` against the `articles` type and does not produce it as
an entity page at all. It is not in the `articles` count, it cannot be a
relation endpoint, and it is not a graph node.

The frontmatter is perfectly good. That is the point: identity is decided by the
filename stem, and a page whose stem cannot be an identity has no identity to
validate fields against.

Nothing renames it automatically. The reported problem carries the suggested
slug (`ferry-terminal-overruns`) and stops there, because renaming a page is an
editorial decision.

The realistic version of this mistake is a file saved out of a word processor,
or dragged in from a shared drive, with the headline as the filename.
